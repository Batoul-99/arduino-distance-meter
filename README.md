# Arduino Distance Meter Project

An Arduino academic project focused on building a digital distance measuring system using Arduino components and sensor-based measurement.

## Project Overview

This project presents the design and implementation of a distance meter using Arduino. It focuses on understanding basic embedded systems concepts, sensor usage, circuit design, and project presentation.
